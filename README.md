# finance

Mobile-first full-stack personal finance web application with digital wallet UX, daily routine expense tracking, habit "What-If" simulator, quick actions for daily expenses, live multi-currency conversion, and an atomic JSON-only database.

## Architecture & Specifications

- [**System Design**](system_design.md): Complete architecture, UI wireframes, data models, workflows, and JSON schema.
- [**Tech Stack**](stack.md): Next.js 15, React 19, Tailwind CSS v4, Framer Motion, Recharts, and Lowdb.
- [**Backend API Endpoints**](backend_endpoints.md): Full RESTful contract for all wallet, routine, and analytics routes.
- [**Phases Plan**](phases_plan.md): Step-by-step phased execution roadmap with Git push gates.
